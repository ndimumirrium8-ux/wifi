# SPHF Wi-Fi Portal

## Project Goal

The goal of this project is to build a simple community Wi-Fi captive portal prototype.

The system will demonstrate how a user can connect to a community Wi-Fi network, reach a portal page, submit basic information, and move through a simple connection flow.

## Main Objectives

- Build a simple Wi-Fi portal interface
- Demonstrate a basic connection flow
- Use fake sample data
- Display connection status
- Handle simple errors
- Understand basic networking concepts
- Consider basic cybersecurity principles
- Practice web development using HTML, CSS and JavaScript

## Important Note

This is a learning prototype.

No real user information, passwords, credentials, phone numbers, or production network information should be used.
