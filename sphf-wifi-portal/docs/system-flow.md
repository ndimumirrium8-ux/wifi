# System Flow

## Basic User Flow

A user connects to the community Wi-Fi network.

The user is directed to the captive portal.

The portal displays a welcome and connection form.

The user submits fake sample information.

The system validates the information.

If the information is accepted, the user sees a connection status page.

If there is a problem, the user sees an error message.

## Flow

User
↓
Wi-Fi Network
↓
Captive Portal
↓
Connection Form
↓
Validation
↓
Success or Error
↓
Status Page
